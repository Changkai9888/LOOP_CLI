# LOOP-CLI 起点 —— 三生万物

**三生万物**是这个最小自举架构的绰号，它是从最基础起点，通过自我对话和演化，逐步成长为完整的 LOOP-CLI 系统。LOOP-CLI 是一个闭环、自激、可演化的 CLI 架构，而三生万物则是这个架构的自举起点与原型。

本项目由三个核心文件组成，每个文件承担不同职能，使系统可以在最小规模下完成自举、对话和初步自我改造：

- `unifiedAPI.py`：统一封装大模型 API 调用，包括普通对话、JSON 输出、工具调用等，为整个 CLI 提供认知能量接口。
- `客户对话.py`：基础对话层，支持连续用户交互、历史日志保存和上下文恢复，是系统最直接的人机交互入口。
- `_治理对话.py`：工程治理层，在提示词上扫描目录、读取文件内容，将工程状态注入系统提示词，让模型以“系统架构师”的身份进行分析和受控代码生成。只有一个写文本文件的技能。需要用户手动开启。

这个最小自举系统的意义在于：它不是永动机，能量来源依赖大模型提供的认知熵减；它也不是终极系统，而是一个实验性的原型。通过不断自我对话和演化，它能够探索更复杂、更智能的 CLI 架构设计。

使用这个最小版本，你可以体验“模型读取工程、理解工程、治理工程、生成工程”的闭环流程，为未来扩展更复杂的 LOOP-CLI 奠定基础。
